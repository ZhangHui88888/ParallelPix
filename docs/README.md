# 文档目录说明

> ParallelPix — 基于 OpenMP 与 CUDA 的电商商品图片并行处理课程项目

## 目录结构

```
docs/
├── README.md
├── plan/      # 项目计划
├── design/    # 需求、功能设计与交互流程
├── tech/      # 技术架构与本地构建运行说明
└── test/      # 正确性、异常与性能实验记录
```
