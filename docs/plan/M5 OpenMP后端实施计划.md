# M5 OpenMP 后端实施计划

## 目标

完成 FR-005，并将真实 OpenMP 后端注册到 M7，在不改变 M1、M2 和 27 列 CSV 契约的前提下打通 Sequential 与 OpenMP 的正确性和性能对比。

## 任务状态

| 任务 | 交付物 | 状态 |
|------|--------|------|
| 调度策略 | 图片级优先、小批次行级回退 | 已实现 |
| OpenMP 处理器 | 可配置线程数、共享公共像素语义、稳定输出顺序 | 已实现 |
| M7 执行器 | `OpenMpExecutor` 与 Pipeline 注册 | 已实现 |
| 构建接入 | `parallelpix_openmp`、`OpenMP::OpenMP_CXX` 和测试目标 | 已实现 |
| 正确性测试代码 | 1/2/4/8 线程、两类调度、输入不变和错误模型 | 已编写；待统一执行 |
| 真实进程测试代码 | Sequential/OpenMP 成功、CUDA 按设备可用性运行或跳过 | 已更新；待统一执行 |
| 性能实验 | 正式数据集线程扩展实验 | 待 M5/M6 统一验证后执行 |

## 完成定义

- OpenMP 目标能够以 Release 配置构建；
- 1、2、4、8 和设备允许的最大线程数可运行；
- OpenMP PNG 与同规模 Sequential PNG 完全一致；
- CSV 正确记录线程数、加速比与并行效率；
- M5/M6 功能代码现已完成；所有 M1～M7 自动化和真实数据性能实验进入统一验证阶段。
