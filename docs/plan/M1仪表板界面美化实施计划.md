# M1 仪表板界面美化实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 将 M1 Streamlit 页面实现为已选定的“数据优先实验工作台”，并在右上角加入当前会话内生效的中英文切换。

**Architecture:** 保留 `BenchmarkRequest`、Runner、CSV 和结果计算逻辑，把本地化、样式、配置表单和结果视图拆成独立展示单元。`page.py` 只负责页面编排；语言代码由页面向侧栏和结果视图显式传递，避免展示状态进入 Benchmark 业务模型。

**Tech Stack:** Python 3.12、Streamlit 1.60.0、Pandas 3.0.5、Plotly 6.9.0、pytest 9.1.1、Streamlit AppTest。

- [ ] **Step 3: 实现最小本地化模块**

`i18n.py` 使用稳定键保存英文和中文，不从界面文案反向推导键。必须包含页面标题、模式、侧栏字段、矩阵摘要、状态、四个标签页、四个指标、空状态、运行上下文、下载按钮和应用错误消息。动态消息使用“完全匹配表 + 前缀表”：

```python
from typing import Literal

Language = Literal["en", "zh"]

COPY = {
    "app_title": {"en": "ParallelPix", "zh": "ParallelPix"},
    "app_subtitle": {
        "en": "Local benchmark console for image-processing performance",
        "zh": "本地图片处理性能基准控制台",
    },
    "configuration": {"en": "Configuration", "zh": "配置"},
    "experiment_matrix": {"en": "Experiment matrix", "zh": "实验矩阵"},
    "run_benchmark": {"en": "Run benchmark", "zh": "运行基准测试"},
    "overview": {"en": "Overview", "zh": "概览"},
    "scalability": {"en": "Scalability", "zh": "可扩展性"},
    "cuda_timing": {"en": "CUDA Timing", "zh": "CUDA 时序"},
    "raw_data": {"en": "Raw Data", "zh": "原始数据"},
    "matrix_counts": {"en": "{count} sets", "zh": "{count} 组"},
    "backend_openmp": {"en": "OpenMP", "zh": "OpenMP"},
}


def tr(key: str, language: Language, **values: object) -> str:
    return COPY[key][language].format(**values)
```

`localize_message` 必须保留未知文本，并翻译已知成功、部分成功、启动失败、CSV 缺失、run_id 缺失、校验失败以及常见路径错误。

- [ ] **Step 3: 实现语言选择和页面编排**

在 `page.py` 使用主区列布局把选择器放在右上角：

```python
def render_language_selector() -> Language:
    selected = st.segmented_control(
        "Language / 语言",
        ("en", "zh"),
        default="en",
        format_func=lambda code: {"en": "EN", "zh": "中"}[code],
        key="ui_language",
        label_visibility="collapsed",
        width="content",
    )
    return "zh" if selected == "zh" else "en"
```

调用顺序固定为：`set_page_config` → `apply_styles` → `_initialize_state` → 标题与语言选择 → `render_sidebar(language)` → 模式提示 → 状态 → 矩阵摘要 → 结果视图。所有已存在的 Session State key 保持不变。
