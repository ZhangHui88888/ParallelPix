# 开发计划

## 项目状态

需求与总体架构已经确认。M1 本地性能仪表板和 M2 CLI Controller 已完成自动化验收；下一步实现 M3 图片数据 I/O 与 M4 Sequential，替换 M2-only Pipeline 并形成端到端基线。

|------|------|--------|------|

| 模块 | 任务 | 状态 |

## 模块边界

- M1 是操作和展示层，不实现图片处理或性能指标计算。
- M2 是 Application Controller，只校验请求并编排 M3～M7，不承载文件解码、像素算法或统计逻辑。
- M3 负责数据进入和输出；M4、M5、M6 只负责各自计算后端；M7 负责验证与实验数据。
- 参数错误、文件错误、CUDA 不可用和显存不足等异常由对应模块识别，统一经 M2 转换为日志和退出码。

## 实施顺序

1. 已完成 M1 可运行 UI、Demo Runner、真实 CLI 适配口、样例 CSV 和浏览器验收。
2. 完成 M2、M3、M4，形成可从终端运行的 Sequential 端到端基线。
3. 完成 M7，将真实 Benchmark CSV 接入 M1。
4. 依次完成 M5、M6，并补齐 CPU/GPU 正确性与性能实验。
5. 回到 M1 完成真实 CLI 联调和最终答辩流程验证。
