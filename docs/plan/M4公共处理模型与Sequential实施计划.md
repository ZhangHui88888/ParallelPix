# M4 公共处理模型与 Sequential 实施计划

## 目标

实现可供 M4～M6 共用的确定性处理语义和单线程 Sequential 后端，完成 FR-003、FR-004，并保持 M2 Controller 与 M7 Benchmark 的模块边界。

## 实施任务

| 任务 | 交付物 | 验证 | 状态 |
|------|--------|------|------|
| 公共契约 | `ProcessingConfig`、裁剪区域、结构化问题和整批结果 | 配置、内存边界和错误模型测试 | 已完成 |
| 几何与数值语义 | 中心裁剪、半像素双线性、舍入限幅、亮度和 Alpha 混合 | 方形、横图、竖图、边缘及通道测试 | 已完成 |
| Sequential 后端 | 无状态单线程批处理，保持顺序和来源路径 | 确定性、输入不变及完整流水线测试 | 已完成 |
| M3 集成 | 解码、处理、显式 PNG 写出和逐像素回读 | Unicode 路径集成测试 | 已完成 |
| 构建与回归 | 独立 processing/sequential 静态库和 M4 测试目标 | Debug/Release CTest、pytest、diff check | 已完成 |
| 文档闭环 | M4 设计、实施、测试和项目状态更新 | 文档索引与实现一致 | 已完成 |

## 全局约束

- OpenCV 仅由 M3 用于解码、编码和内存接入，不用于 M4 核心算法。
- Sequential 不链接 OpenMP，不创建线程，不提前实现 OpenMP/CUDA 策略。
- M4 不生成 CSV，不实现预热、重复测量、统计、自动输出命名或 CLI 成功路径。
- 水印保持原尺寸，使用 32px 右/下边距；无法完整放入时整批失败。
- 任一输入无效时不返回部分输出。

## 完成定义

- 公共像素语义有确定的舍入、边界和 Alpha 规则。
- Sequential 输出尺寸、顺序、来源路径及输入不变性通过自动化测试。
- M3→M4→PNG 集成在 Unicode 路径下逐像素回读一致。
- Debug/Release 使用 `/W4 /permissive- /utf-8` 无警告构建。
- M1～M3 回归全部通过。
- M4 阶段曾保持占位失败边界；当前 Sequential 成功、PNG 和 CSV 行为由 M7 覆盖。
