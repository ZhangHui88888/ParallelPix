# M1 本地性能仪表板测试记录

## 认证要求

无。应用仅在本机运行，不提供账号、远程访问或外部 API。

## 前置条件

- Windows 11、Python 3.12。
- 使用 `requirements-dev.txt` 安装固定依赖。
- Demo 流程不依赖 M2、OpenCV、CUDA Toolkit 或真实图片。
- Local CLI 异常测试使用不存在的默认 CLI 和数据路径。

## 执行方式

```powershell
.\.venv\Scripts\python.exe -m pytest -q
.\.venv\Scripts\python.exe -m streamlit run tools/dashboard.py
```

## 输入与输出

- 输入：页面表单生成的 `BenchmarkRequest`，或 Demo Runner 的固定请求。
- 输出：运行状态、最近 500 行日志、只读 CSV 表格和 Plotly 图表。
- Demo 数据：明确标记为虚构数据，不代表真实性能。
